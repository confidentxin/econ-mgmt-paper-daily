# 精选与校准

## 一篇论文怎么变成精选

1. **采集与去重**：每 3 小时按 ISSN 向 Crossref 查询新登记记录，用 DOI 去重。勘误、目录、编委页等非研究条目直接剔除。
2. **等待材料**：只有标题、没有摘要或正文的论文先等待补充，不凭标题评分或生成中文解读。Elsevier 等来源的摘要缺口是当前主要瓶颈。
3. **预筛**（`prefilter.md`）：判断是否属于经济学或管理学研究。明显无关的材料不进入公开池；边界情况继续评估。
4. **两次独立评分**（`selection-score.md`）：模型在看不到期刊名的情况下，对问题与贡献、新颖性、证据强度、研究生相关性和可用性各打 0–10 分，再按论文类型加权为 0–100 分。每篇独立评两次，取平均分展示。
5. **结构化**（`structure.md`）：同时确定领域、论文类型和话题标签。当前七个领域是经济学、金融、会计、管理学、营销、信息系统、交叉与其他。本站不追踪公司主体。
6. **中文写作**：入选和接近入选的论文生成中文标题、摘要与推荐理由；其余达到浏览下限的材料生成较简短的标题摘要。
7. **发布与报告**：达到期刊门槛的论文进入精选候选，再经同一论文的版本归组和新增价值判断决定是否展示。日报每天北京时间 08:00 出刊，最多 12 条主精选、每本期刊最多 2 条；另有周报、月报、RSS、公开 API 和 MCP。

提示词位于 `industry/prompts/`。提示词版本按内容哈希记录；修改后只影响新处理的材料，不会自动重算旧材料。

## 期刊等级与摘要评分如何结合

期刊等级不直接加进模型分数，也不由模型猜测。它通过信源分级决定入选门槛，从而让高水平期刊的论文更容易进入精选：

```ts
export const SELECTION = {
  thresholds: { T1: 60, T1_5: 65, T2: 76 },
  classes: { adjacent: { label: "相邻学科期刊", threshold: 72 } },
  understandFloor: 50,
  browseFloor: 40,
};
```

- `T1`：UTD24 / FT50 期刊，平均分至少 60。
- `T1_5`：其余 ABS 3/4 期刊，平均分至少 65。
- `T2`：其他来源，平均分至少 76。
- `adjacent`：环境科学、工程、人体工效学等相邻学科期刊的最低 72 分，只抬高、不降低原门槛。
- 两次评分之和必须达到 `2 × 最终门槛`。没有门槛的分级不参与精选评分。
- `understandFloor` 以上使用完整中文解读写法；`browseFloor` 以下不出现在“全部动态”，搜索不受此下限影响。

**这些数字是未经人工样本校准的起点值，不是从期刊数据拟合出来的结论。** 期刊名录暂未区分 ABS 3 星、4 星和 4*，因此都放在 `T1_5`。被引次数和下载量尚未接入热度或评分；后续加入时应保留快照、来源和时间，并单独评估是否改善推荐，而不是直接叠加一个未经验证的分数。

## 如何校准

### 1. 准备标注样本

从实际采集到的论文中挑 100–200 条，由目标读者标注“该选 / 不该选”，保存为 `.data/gold.jsonl`。该目录不进 Git。格式和字段见 `scripts/eval-selection.ts` 与后台 SelectBench；样本应覆盖高分、低分和临界情况，并包含不同领域、论文类型和期刊等级。

### 2. 运行评测

```bash
node --env-file=.env scripts/eval-selection.ts --gold .data/gold.jsonl --split development --label "经管第一版"
```

报告给出查准率、查全率、F1、覆盖率，以及不同门槛下的结果。调提示词和门槛时看开发集，最后用留出集检查，避免只记住样本。模型调用会产生费用，应先用小批量试跑。

### 3. 看错例再调整

优先检查三类错误：好期刊的低价值论文为何入选、重要但非核心期刊的论文为何漏选、摘要材料不足是否导致误判。调整 `industry/prompts/selection-score.md` 或 `industry/selection.ts` 后重跑；不要为了让报告好看而删除难例。
